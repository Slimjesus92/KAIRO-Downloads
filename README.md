# KAIRO Downloads

Official public downloads for the KAIRO Android and Android TV app.

## Download

The latest signed APK is always available here:

[**Download the latest KAIRO APK**](https://github.com/Slimjesus92/KAIRO-Downloads/releases/latest/download/KAIRO.apk)

## Install

1. Open the Downloader app on your Android TV.
2. Enter the KAIRO Downloader code (to be added once the download URL is registered).
3. Download the APK and allow installation when Android asks.

Only install KAIRO APKs published in this repository.
